How it works

  1. You pick an image (or use the sample sloth).
  2. We resize it, adjust contrast/brightness, then convert each pixel to the nearest color in a tiny palette.
  3. The dithering method decides how we sprinkle the "missing" color information to fake more shades.

Ordered dither is clean + poster-like. Error diffusion is softer + more photo-ish.
